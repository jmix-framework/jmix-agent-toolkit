## Jmix

This is a Jmix 2 application. Before writing or changing Java code, view
descriptors, Liquibase changelogs, or build files, read the `jmix` skill and
follow it. It says which skill covers each artifact, which source wins when
they disagree, and which checks close a task. Edits to documentation only, or
to the text of existing message keys, do not need it.

Your Jmix/Vaadin priors are not reliable here: verify API names as the `jmix`
skill describes, not from memory.

Managed by the Jmix Agent Toolkit. Content between these markers is replaced on
re-install — put your own instructions outside them.
